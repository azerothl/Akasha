# Akasha

Akasha associe un assistant à des documents, notes, actions et sujets suivis. L’installation locale s’articule autour du daemon et de ses interfaces.

## Configurer et diagnostiquer

Consulter le guide utilisateur pour choisir un fournisseur de modèle, configurer les données de travail et utiliser les interfaces. La commande akasha doctor donne l’état de l’installation. Le daemon utilise le port 3876 par défaut.
