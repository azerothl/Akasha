# Préparation de la release Akasha 0.12.1

État relevé le 24 octobre 2026. Cette branche prépare la version ; aucun tag ni release publique n’est créé ici.

## Version

- Dernière release publiée : `v0.12.0`.
- Versions Cargo, Tauri et npm synchronisées sur `0.12.1` avec `scripts/sync-release-version.py`.
- La release inclut les changements fusionnés depuis `v0.12.0` : correctifs de packaging Linux/macOS (#261, #262, #264, #265), mises à jour Windows (#266), catalogue de modules Akasha (#267), contexte Ollama (#268), réponses humaines dans le chat (#269) et routage strict des modèles gratuits (#270).

## Validations déjà observées

- Les contrôles CPU des PR #266 à #270 sont passés avant fusion, y compris les suites Rust et les tests llama.cpp de #270.
- Le job GPU de #270 est resté en file d’attente : aucun runner GPU n’est configuré pour le dépôt. La validation CUDA n’est donc pas confirmée.
- Le graphe d’architecture JSON et sa copie embarquée dans le diagramme sont synchronisés pour la version 0.12.1 ; leur égalité et les références des nœuds, arêtes et parcours ont été vérifiées localement.
- La matrice de compilation et les tests de premier démarrage des archives de release n’ont pas encore été lancés.

## Avant publication

1. Valider et intégrer cette PR après ses contrôles CI.
2. Lancer la workflow `Release` sans publication pour construire les archives et vérifier leur premier démarrage sur les plateformes prises en charge.
3. Ne publier `v0.12.1` qu’après réussite de cette matrice. Le push du tag déclenche ensuite le workflow qui publie les archives et la release GitHub.
