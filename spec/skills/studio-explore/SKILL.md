# Explorer un dépôt

Lire les instructions AGENTS.md applicables, les manifestes et la documentation du projet. Utiliser le manifeste effectif pour choisir les outils disponibles. Privilégier recherche ciblée et fenêtres de lecture ; conserver les chemins et lignes qui étayent les conclusions.

Décrire le flux réel de la fonctionnalité concernée : entrée, traitement, stockage, sortie. Distinguer code présent, comportement observé et proposition. Identifier les changements utilisateur à préserver et les dépendances externes manquantes.

Produire une carte courte des fichiers utiles, les conventions à suivre et un plan limité à la demande. Une exploration ne lance ni installation ni commande susceptible de modifier le dépôt. Pour poursuivre, le rôle et la demande doivent autoriser l’implémentation ; ce skill ne crée aucune permission.
