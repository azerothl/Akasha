# Mode Dégradé Sécurisé

Le mode dégradé s’active automatiquement si :

- Perte cluster
- Perte modèle principal
- Corruption mémoire partielle
- Problème critique sécurité

## Capacités Maintenues

- Accès mémoire locale
- Interaction utilisateur
- Journalisation
- Gestion tâches critiques

## Capacités Désactivées

- Exécution plugins non validés
- Appels API externes
- Spawn agents avancés

Objectif : 
Maintenir sécurité et stabilité avant performance.
